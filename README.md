# 🛒 Amazon UI Clone

A fully functional frontend clone of the Amazon e-commerce web application. This project was built to demonstrate proficiency in modern web development, complex state management using Redux, and responsive UI/UX design.

## ✨ Features

*   **Pixel-Perfect UI:** A responsive design that closely mirrors the official Amazon interface across devices.
*   **Dynamic Product Carousel:** Interactive image sliders for browsing product categories and promotions.
*   **State Management (Redux):** 
    *   Add products to the shopping cart.
    *   Remove products from the shopping cart.
    *   Real-time cart item count and subtotal calculation.
*   **Product Listing:** Dynamic rendering of products using component-based architecture.

## 🛠️ Tech Stack

*   **Frontend Framework:** React.js
*   **State Management:** Redux 
*   **Languages:** JavaScript (ES6+), HTML5, CSS3
*   **Icons/Typography:** Material-UI Icons / FontAwesome
